# 구매요청 상세 작성자 지원 차단

> 범위: 구매요청 상세에서 작성자 본인에게 판매자 지원 진입점을 노출하지 않는다.

## 사용자 경험

- 요청 작성자가 자신의 상세 페이지를 보면 `내가 등록한 요청이에요` 안내를 본다.
- 이 상태에서는 `이 요청에 지원하기` 버튼을 렌더링하지 않는다.
- 비로그인 사용자와 다른 사용자는 기존의 비활성 지원 안내 버튼을 계속 본다. 실제 판매자 지원 기능은 이번 범위에 포함하지 않는다.

## API 계약

- `GET /api/requests/{id}`는 공개 요청 필드에 `isOwner: boolean`을 추가한다.
- `isOwner`는 유효한 세션 사용자의 ID와 요청의 `requester_id`가 일치할 때만 `true`이다.
- 세션이 없거나 유효하지 않거나 다른 사용자의 세션이면 `false`이다.
- `requester_id`는 계속 외부 응답에 포함하지 않는다.

## 프런트엔드 데이터 흐름

- 서버 컴포넌트의 상세 조회는 현재 요청의 Cookie 헤더를 same-origin API 요청으로 전달한다.
- 상세 페이지는 `isOwner`에 따라 작성자 안내 또는 기존 지원 안내 버튼을 조건부 렌더링한다.

## 검증

- 작성자·비로그인·타 사용자 상세 API 응답의 `isOwner` 값을 계약 테스트로 검증한다.
- 작성자 화면에서 지원 버튼이 사라지고, 비작성자 화면에서 기존 버튼이 유지되는지 UI 테스트로 검증한다.
